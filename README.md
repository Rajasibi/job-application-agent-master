A local job application pipeline: **n8n** (orchestration) + **Ollama / Qwen 2.5 7B** (scoring, CV tailoring, cover letters) + **Playwright** (scraping and form filling). It runs entirely on this machine and costs nothing to run.

**Manual final submit:** the agent finds jobs, scores them, tailors your CV, and prepares or fills the application, but **it never clicks the final Apply or Submit**. It actively utilizes stealth plugins to automatically bypass standard bot checks (like Cloudflare), but it stops on strict CAPTCHAs, OTPs, and questions it can't answer from your data. Every prepared application waits in the dashboard. You open it, check it, and submit it yourself.
